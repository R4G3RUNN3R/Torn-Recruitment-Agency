# Recruitment Agency v4.3 Google Sheets Global Intelligence Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an optional shared Google Sheets intelligence layer that accepts only sanitized Torn player observations, preserves local-first precedence, queues failed uploads, and exposes shared history without ever sending recruiter-private data.

**Architecture:** Add a focused `src/global-core.js` UMD/CommonJS module for sanitization, payload construction, response normalization, provenance, dedupe helpers, and retry classification. Keep persistence/network orchestration in the userscript, add three additive IndexedDB v10 stores, and include a reproducible Google Apps Script service under `global/google-apps-script/`. The Google Sheet remains private; the Apps Script web app is the only public interface.

**Tech Stack:** Vanilla JavaScript userscript, Node 20 `node:test`, IndexedDB, Fetch API, Google Apps Script, Google Sheets.

## Global Constraints

- Version target is `4.3.0`.
- IndexedDB upgrade is additive from version `9` to `10`; never delete or recreate existing `users`, `meta`, `scoutLatest`, or `scoutHistory` stores.
- Torn API scheduler remains hard-capped at `75` calls/minute with minimum `800 ms` spacing.
- Global Google requests are not routed through the Torn API scheduler.
- Only this whitelist may leave the browser: `playerId`, `name`, `observedAt`, `level`, `ee`, `activity30`, `xanax30`, `refills30`, `attacks30`, `rwHits30`, `networth`, `fit`, `fitType`, `lastActive`, `scoutStatus`, `sourceVersion`.
- Never upload Torn API keys, recruiter notes, recruitment status, contact history, message contents, recruiter-entered pay/role/availability, settings blobs, or arbitrary Scout objects.
- Fresh direct Torn data outranks local cache; local cache outranks global; global outranks older historical data and parsed forum information.
- Global service failure must never fail an otherwise successful Scout operation.
- Google Sheet tabs are fixed to `Players`, `Observations`, and `Meta`; clients cannot supply tab names, ranges, formulas, or column indexes.
- Duplicate material observations inside `30 minutes` are accepted as deduped success without adding another historical row.
- Returned player history is capped at `100` newest observations.
- Existing paid/protected Recruit Scout backends remain forbidden.

- [ ] **Step 3: Implement the UMD/CommonJS module and explicit whitelist sanitizer**

Use this shape:

```js
(function (root, factory) {
  const api = factory();
  if (typeof module === 'object' && module.exports) module.exports = api;
  if (root) root.RA_GlobalCore = api;
})(typeof globalThis !== 'undefined' ? globalThis : this, function () {
  'use strict';

  const GLOBAL_SCHEMA_VERSION = 1;
  const GLOBAL_FIELDS = Object.freeze([
    'playerId','name','observedAt','level','ee','activity30','xanax30','refills30',
    'attacks30','rwHits30','networth','fit','fitType','lastActive','scoutStatus','sourceVersion'
  ]);
  const MATERIAL_FIELDS = Object.freeze([
    'level','ee','activity30','xanax30','refills30','attacks30','rwHits30',
    'networth','fit','fitType','lastActive'
  ]);

  function finiteOrNull(v) {
    if (v === null || v === undefined || v === '') return null;
    const x = Number(v);
    return Number.isFinite(x) && x >= 0 ? x : null;
  }

  function safeText(v, max) {
    let s = String(v ?? '').trim().slice(0, max);
    if (/^[=+\-@]/.test(s)) s = `'${s}`;
    return s;
  }

  function sanitizeObservation(input, sourceVersion) {
    const playerId = Number(input?.playerId ?? input?.userId ?? input?.id);
    const observedAt = Number(input?.observedAt ?? input?.capturedAt);
    if (!Number.isSafeInteger(playerId) || playerId <= 0) throw new Error('Invalid playerId');
    if (!Number.isFinite(observedAt) || observedAt <= 0) throw new Error('Invalid observedAt');
    return {
      playerId,
      name: safeText(input?.name, 32),
      observedAt,
      level: finiteOrNull(input?.level),
      ee: finiteOrNull(input?.ee),
      activity30: finiteOrNull(input?.activity30),
      xanax30: finiteOrNull(input?.xanax30),
      refills30: finiteOrNull(input?.refills30),
      attacks30: finiteOrNull(input?.attacks30),
      rwHits30: finiteOrNull(input?.rwHits30),
      networth: finiteOrNull(input?.networth),
      fit: finiteOrNull(input?.fit),
      fitType: safeText(input?.fitType || '', 24),
      lastActive: finiteOrNull(input?.lastActive),
      scoutStatus: safeText(input?.scoutStatus || '', 24),
      sourceVersion: safeText(sourceVersion || input?.sourceVersion || '', 16)
    };
  }
```

Start with constants and helpers:

```js
const SCHEMA_VERSION = 1;
const SERVICE_VERSION = '4.3.0';
const DEDUPE_WINDOW_MS = 30 * 60 * 1000;
const MAX_HISTORY = 100;
const PLAYERS = 'Players';
const OBSERVATIONS = 'Observations';
const META = 'Meta';
const OBS_HEADERS = ['playerId','name','observedAt','level','ee','activity30','xanax30','refills30','attacks30','rwHits30','networth','fit','fitType','lastActive','scoutStatus','sourceVersion'];
const PLAYER_HEADERS = [...OBS_HEADERS, 'firstSeen', 'observationCount'];

function json_(obj) {
  return ContentService.createTextOutput(JSON.stringify(obj)).setMimeType(ContentService.MimeType.JSON);
}

function doGet(e) {
  const action = String(e?.parameter?.action || 'meta');
  if (action === 'player') return json_(handlePlayer_(e.parameter.id));
  if (action === 'meta') return json_(handleMeta_());
  return json_({ok:false, code:'INVALID_ACTION'});
}

function doPost(e) {
  try {
    const raw = String(e?.postData?.contents || '');
    if (!raw || raw.length > 16384) return json_({ok:false, code:'INVALID_BODY'});
    const payload = JSON.parse(raw);
    if (payload.action !== 'observe') return json_({ok:false, code:'INVALID_ACTION'});
    return json_(handleObserve_(payload));
  } catch (error) {
    return json_({ok:false, code:'INVALID_BODY'});
  }
}
```

`sanitizePayload_` must reconstruct a new object from explicit fields, reject unsupported schema, validate positive safe integer player ID, reject future timestamps beyond 10 minutes, cap strings, and only accept finite non-negative numeric values within broad sanity bounds. Do not copy unknown properties.
