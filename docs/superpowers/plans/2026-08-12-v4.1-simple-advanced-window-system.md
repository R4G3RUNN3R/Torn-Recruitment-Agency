# Recruitment Agency v4.1 Simple/Advanced + Window System Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship v4.1.0 with a Simple-first interface, Advanced-only technical controls, a Torn Information sidebar launcher, readable theme text, a hard 75 calls/minute Scout scheduler, and a shared persistent floating-window manager.

**Architecture:** Keep the current single userscript and existing Scout core. Add one shared UI complexity state, one shared window-manager implementation, and one sidebar-launcher implementation inside the userscript. Preserve all existing IndexedDB stores/data and extend metadata only. Every Scout API request continues through `reserveScoutCall()` and every managed window uses the same geometry/z-index helpers.

**Tech Stack:** Tampermonkey userscript JavaScript, Torn API v2, IndexedDB, DOM/MutationObserver, CSS variables, Node.js built-in test runner, GitHub Actions.

## Global Constraints

- Release version is `4.1.0`.
- Simple mode is the default for users without a saved complexity setting.
- Switching Simple/Advanced never resets stored settings.
- Fit targets and weights remain available in Simple mode inside collapsed `Fit Settings`.
- Scout API default rate is 75 calls/minute.
- Scout API hard maximum is 75 calls/minute.
- Scheduler spacing at the cap is at least 800 ms between Scout API reservations.
- Multiple workers cannot bypass the shared scheduler.
- Dark theme primary text is `#39ff14` and must remain readable in inputs, buttons, links, tables, labels, and help text.
- Light theme primary text is `#000000`; muted text is dark.
- Torn Information sidebar icon is primary launcher; floating `RA` is fallback-only.
- Main, Results, and History windows are independently movable/resizable and may remain open simultaneously.
- IndexedDB migration/settings changes are additive and non-destructive.
- No dependency on `rs.dnonetwork.com`, Recruit Scout membership/auth/payment, or proprietary grading endpoints.
