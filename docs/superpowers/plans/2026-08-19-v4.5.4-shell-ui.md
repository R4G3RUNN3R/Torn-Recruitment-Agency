# Recruitment Agency v4.5.4 Shell UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship v4.5.4 with a genuinely scrollable routed content viewport, a single Settings entry point in the title bar, and viewport Maximize/Restore that preserves the user's normal window geometry.

**Architecture:** Keep the current managed `#ra-app` shell and routing model. Make the existing `.ra-content` the constrained scroll owner, filter Settings only from the rendered sidebar, and add transient maximize state plus small geometry helpers in `src/v45-app.js`. Do not change IndexedDB schema or recruitment/intelligence behavior. Because `src/v45-app.js` changes, create a new immutable runtime snapshot commit before updating the public userscript `@require` pins.

**Tech Stack:** JavaScript userscript, Node 20 `node:test`, Puppeteer/Chromium browser regressions, IndexedDB, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-08-19-v4.5.4-shell-ui-design.md`

## Global Constraints

- Public userscript/package release target: `4.5.4`.
- The runtime module changed by this release must report `SCRIPT_VERSION = '4.5.4'`; the bootstrap must require that exact version.
- IndexedDB version remains `12`, additive only.
- Never call `deleteObjectStore`.
- Torn API hard maximum remains `75` calls/minute.
- Minimum Recruitment Agency Torn API request gap remains `800 ms`.
- Do not change Scout, Smart Match, Global Intelligence, forum discovery, candidate pipeline semantics, messaging, privacy boundaries, or API scheduling.
- Keep v4.5.3 top-frame, DOM singleton, legacy-cleanup and click-interference protections intact.
- Settings stays a real routed page; only its sidebar button is removed.
- Maximize is viewport maximize, not the Fullscreen API, and maximized state is session-only.
- Persist only normal-window geometry in `meta.ui.windowGeometry.main`.
- Preserve existing 421 px mobile behavior and physical-click regressions.

- [ ] **Step 3: Centralize geometry reading/clamping/application**

Implement helpers equivalent to:

```js
function readAppGeometry(app=document.getElementById('ra-app')){
  if(!app)return null;
  const r=app.getBoundingClientRect();
  return {x:r.left,y:r.top,width:r.width,height:r.height};
}

function clampWindowGeometry(g){
  const minW=Math.min(560,innerWidth-8);
  const minH=Math.min(420,innerHeight-8);
  const width=Math.max(minW,Math.min(number(g?.width,900),innerWidth-8));
  const height=Math.max(minH,Math.min(number(g?.height,650),innerHeight-8));
  return {
    x:Math.max(4,Math.min(number(g?.x,20),Math.max(4,innerWidth-width-4))),
    y:Math.max(4,Math.min(number(g?.y,50),Math.max(4,innerHeight-height-4))),
    width,height
  };
}

function applyWindowGeometry(app,g){
  if(!app||!g)return;
  app.style.left=`${g.x}px`;
  app.style.top=`${g.y}px`;
  app.style.width=`${g.width}px`;
  app.style.height=`${g.height}px`;
}
```

Refactor `restoreGeometry()` to use these helpers, preserving DB12 metadata shape.

- [ ] **Step 4: Add Maximize/Restore behavior**

Implement:

```js
function syncMaximizeButton(){
  const button=document.getElementById('ra-maximize');
  if(!button)return;
  const label=state.maximized?'Restore':'Maximize';
  button.textContent=label;
  button.title=label;
  button.setAttribute('aria-label',label);
}

function maximizeApp(){
  const app=document.getElementById('ra-app');
  if(!app||state.maximized)return;
  state.restoreGeometry=readAppGeometry(app);
  state.maximized=true;
  app.classList.add('ra-maximized');
  syncMaximizeButton();
}

async function restoreApp(){
  const app=document.getElementById('ra-app');
  if(!app||!state.maximized)return;
  const target=clampWindowGeometry(state.restoreGeometry||readAppGeometry(app));
  state.maximized=false;
  app.classList.remove('ra-maximized');
  applyWindowGeometry(app,target);
  state.restoreGeometry=null;
  syncMaximizeButton();
  await saveGeometry();
}

async function toggleMaximize(){
  if(state.maximized) await restoreApp();
  else maximizeApp();
}
```

If implementation timing requires one animation frame after removing the class before applying inline geometry, make that explicit in code and keep the test tolerant to one CSS pixel.
